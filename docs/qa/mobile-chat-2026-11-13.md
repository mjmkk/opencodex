| 失败反馈与底部跟随 | 内部错误直接显示，气泡可能在输入框下不可见 | 改为中文网络错误；本地发送后滚到新气泡，复验失败红标、重试气泡和回复均可见 |

## 实现边界

- 发件箱以连接 scope 和 thread id 隔离；切换连接后重建页面，旧任务不得向新连接继续发。
- 重试持久保留原消息 ID 及 native/harness 路径，避免换通道重复写。
- 进程退出时仍处于 pending 的消息，在下次启动显示“发送被中断，请点按重试”，不盲目自动重发。
- `unconfirmed` 与 `duplicate` 显示“发送结果待确认”，只有真实用户记录匹配后才收起本地气泡。
- 当前可见聊天持续读取最新回复；切页取消读取，回前台恢复。更早历史仍来自 Mirror，加载历史时保留已读的新消息。
- 最近对话落盘上限 500 行；草稿单独写小文件，避免每次按键重新编码整段历史。
